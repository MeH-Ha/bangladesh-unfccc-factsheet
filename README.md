# UNFCCC in Bangladesh: A Factsheet

An interactive web version of a three-page factsheet on how Bangladesh puts the UN Framework Convention on Climate Change into practice, and how it speaks up in the world climate talks.

**Read online:** https://meh-ha.github.io/bangladesh-unfccc-factsheet

By Mehedi Hasan, for *Environmental Policies and Governance* (Erasmus Mundus GLOBE, Ciências ULisboa).

## What is in this repository

| File | Purpose |
|---|---|
| `index.html` | The factsheet page |
| `style.css` | Layout, colours and responsive rules |
| `app.js` | Hover and tap interactions, charts, citation pop-ups |
| `assets/` | Images, social preview and web fonts |
| `.nojekyll` | Tells GitHub Pages to serve the files exactly as they are |

No build step is needed. It is plain HTML, CSS and JavaScript.

## Interactions

- Hover or tap any grey citation to see its full APA 7th reference.
- Hover or tap the map pins and the hazard list to link them.
- Hover or tap the chart bars and the doughnut slices for details.
- Works with keyboard and touch, and respects reduced-motion settings.
